# История изменений

Формат основан на Keep a Changelog.

## [Unreleased]

### Добавлено

- Импорт кода версии 2.5.7 из монолитного установщика `install_tgbot_v2.5.7.sh` в обычное дерево репозитория.
- Полный отчёт аудита: `docs/AUDIT.md`.
- Проектная документация: `docs/ARCHITECTURE.md`, `docs/INSTALL.md`, `docs/CONFIGURATION.md`, `docs/ROADMAP.md`.
- Модульный установщик `scripts/install.sh`, который ставит бота из репозитория.
- Пример конфига `config.example.yaml` и `.gitignore`.

### Изменено

- `systemd/tg2printer.service`: пути развёрнуты из переменных установщика; `ReadWritePaths` для файла лога получил префикс `-` (аудит P1-1).
- `config.example.yaml`: `python` указывает на `/opt/tgbot/bin/python` (аудит P0-2).
- CI запускает тесты с `PYTHONPATH=.` и кладёт конвертер в `/root/gif2klipper.py` (аудит T-2, T-3).

### Известные проблемы

Три блокера из аудита ещё не исправлены в коде — ставить в боевом режиме нельзя:

1. P0-1 `handlers.py:180` — вызов несуществующей `anims.start_session`.
2. P0-2 — конвертер без Pillow при `python: python3`.
3. P0-3 `errorlog.py` — утечка соединений SQLite.
